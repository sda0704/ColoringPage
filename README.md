Описание предметной области 

Программа создания раскрасок по номерам – это программа, в которой пользователь может загрузить изображение, разбитое на пронумерованные области (где каждый номер соответствует определенному цвету), и с помощью выбора цветов из палитры закрашивать эти области в соответствии с их номерами. В ходе работы программы каждый закрашенный участок сразу отображается на экране, формируя постепенно готовую раскраску.

В системе должен быть представлен один действующий пользователь.
На основании анализа требований в программе должны быть реализованы следующие прецеденты:

1.	Прецедент «Загрузка раскраски». Прецедент позволяет пользователю загрузить раскраску по номерам из текстового файла.
2.	Прецедент «Выбор цвета». Прецедент позволяет пользователю выбрать цвет из палитры для закрашивания областей.
3.	Прецедент «Закрашивание области». Прецедент позволяет пользователю закрашивать пронумерованные области соответствующим цветом.
4.	Прецедент «Отслеживание прогресса». Прецедент позволяет пользователю видеть уже закрашенные области.
5.	Прецедент «Проверка корректности закрашивания». Прецедент позволяет программе проверять соответствие выбранного цвета номеру области и выводить ошибку при попытке закрасить область неправильным цветом.
6.	Прецедент «Валидация файла раскраски». Прецедент позволяет программе проверять корректность формата загружаемого файла и выводить ошибку при обнаружении несоответствия требуемой структуре данных.
